PDF Toolbox — Application Bureau PDF Toolbox — Desktop App

Application bureau PySide6 pour manipuler des PDF : fusion, réorganisation par glisser-déposer, prévisualisation par vignettes, filigrane et caviardage (redaction). Packagée en exécutable Windows autonome via PyInstaller.

A PySide6 desktop application to manipulate PDFs: merge, drag-and-drop reordering, thumbnail preview, watermarking and redaction. Packaged as a standalone Windows executable via PyInstaller.

Python PySide6 PyMuPDF PyInstaller
Code sur demande Code on request

Fonctionnalités

Features

  • Ajout de fichiers par glisser-déposer ou sélecteur (PDF & images).
  • Réorganisation par glisser-déposer dans la liste.
  • Prévisualisation par vignette (première page).
  • Filigrane avec aperçu superposé sur la vignette, appliqué au PDF fusionné final.
  • Caviardage (redaction) pour masquer du contenu sensible.
  • Fusion & sauvegarde en un seul document.
  • Add files via drag-and-drop or a file chooser (PDF & images).
  • Reorder files by dragging inside the list.
  • Thumbnail preview (first page).
  • Watermark with an overlay preview on the thumbnail, applied to the final merged PDF.
  • Redaction to hide sensitive content.
  • Merge & save into a single document.

Architecture logicielle

Software Architecture

Séparation claire UI / cœur métier :

  • core/ : pdf_renderer, watermark, redaction, exporter — logique indépendante de l'interface.
  • ui/ : main_window, page_grid, pdf_canvas, tools_dock — vues PySide6.
  • Profils de filigrane stockés en JSON (watermark_profiles.json).

Rendu PDF via PyMuPDF (insert_textbox pour le filigrane), packaging PyInstaller (--onefile --windowed).
